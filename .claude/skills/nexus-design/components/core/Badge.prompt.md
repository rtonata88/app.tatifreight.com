Counts, categories, tags and reference codes - the flat-cornered, wash-filled sibling of `StatusPill`.

```jsx
<Badge>142 payslips</Badge>
<Badge tone="brass" mono>QT-2026-0184</Badge>
<Badge tone="negative">Disciplinary</Badge>
```

Status goes to `StatusPill`. Quantities, taxonomies and identifiers go to `Badge`.
